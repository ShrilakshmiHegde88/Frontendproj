# Aradhya Nilayam — React Front-End Assignment

Desktop-first React recreation of the housewarming invitation shown in the supplied reference video.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Included interactions
- Smooth Home/Gallery navigation
- Live countdown to 6 September 2026, 9:45 AM
- Open in Maps buttons
- Contact/call buttons
- Mute/sound toggle UI
- Schedule carousel
- RSVP / wishes form
- Generate-wish button with a client-side preset message
